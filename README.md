# ASAP Brain — 新デザイン試用版

架空のゴール・ブランド・仕事だけを使った静的デモです。本番サービスや会社データには接続しません。

## 試せること

- ゴール一覧、詳細、全体ツリー
- AIに渡す指示文のプレビュー
- 合成Codex / Claude Code履歴の解析と候補のJSON書出し

本番への保存、AI起動、MCP、会社の共有DBは含みません。秘密情報や実業務ログをこの公開リポジトリへコミットしないでください。

## デプロイ

`docs/` の検証済み6ファイルだけを配信します。GitHub Pages標準のブランチ公開（main /docs）を利用します。push前に下記の検証を実施してください。独自ワークフローによる自動検証は未設定です。
`node scripts/verify-public.mjs` でファイル許可リスト、秘密情報・実業務名、通信制限、JavaScript構文を検査します。

非公開アプリのソース、DB、認証情報、実行ログは含めません。履歴はブラウザ内で解析し、外部通信はCSPで禁止します。ローカルファイルの選択は利用者自身の操作でのみ行われます。
